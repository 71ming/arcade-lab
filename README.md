# Arcade Lab

一个轻量、好玩的浏览器小游戏合集，打开 `index.html` 即可游玩。

A polished browser game arcade. Open `index.html` in a modern browser to play.

## 游戏 / Games

- CPS 测试 / CPS Test
- 反应速度 / Reaction Speed
- 记忆挑战 / Memory Challenge
- 打字挑战 / Typing Challenge
- 节奏挑战 / Rhythm Challenge
- 躲避游戏 / Dodge
- 迷宫 / Maze
- 2048
- 知识问答 / Quiz
- 电子宠物 / Virtual Pet
- 互动故事 / Interactive Story

## 特点 / Features

- 单文件、无需构建工具或依赖 / Self-contained single-file app with no build step
- 支持桌面和移动端 / Desktop and mobile friendly
- 2048 支持键盘方向键、WASD 和触摸滑动 / 2048 supports arrow keys, WASD, and touch swipes
- 记录部分游戏的本地最佳成绩 / Local best scores for selected games

## 运行 / Run

直接双击 `index.html`，或使用任意静态文件服务器打开它。

Open `index.html` directly, or serve the folder with any static file server.
